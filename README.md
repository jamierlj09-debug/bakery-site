# Hearth & Crumb

A responsive one-page local bakery website, built with plain HTML, CSS and original inline SVG illustrations. No dependencies or build step.

## Website
https://jamierlj09-debug.github.io/bakery-site/

## Customise
Edit `index.html` to replace the sample bakery name, sample story and illustrative menu. Replace the bracketed address, opening hours, email and phone with verified business details. Add accurate allergen information and pricing if needed. Remove the sample-site notices when all content has been verified.

The site is static and has no ordering system, enquiry form, backend, tracking or data storage. Contact placeholders are intentionally not linked.

## Publishing
GitHub Pages serves `main` from the repository root. Committed changes normally appear within a few minutes.
